mc263 · 单文件构建配置

winetricks 风格：勾选组件 → 自动下载 → 打包成 Linux 单文件 / rpm

① 选择组件

只下载官方公开资源；首次运行会校验 SHA1 并缓存，重复构建不会重复下载。

② 基本设置

配置会保存到 ~/.config/mc263/config.json，下次打开自动恢复。

③ 额外 mods URL

填写 .jar 直链；下载到游戏文件目录的 mods/ 并随单文件打包。

④ 执行

顺序：mc263-fetch 下载 → mc263-build 构建单文件 → build-rpm.sh 打包。
