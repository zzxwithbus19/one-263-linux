mc263是Minecraft的Linux启动器#仅限java版，不支持微软账户登录

安装 mc263
~/.local/share/mc263
minecraft/            游戏目录，首次运行自动建
├── versions/
│   ├── 26.3/          mods saves logs …
│   └──
.mc263/
├── config.json        版本 / 内存 / Java / 镜像
└── mc263_downloader.py 运行时释放的下载脚本

运行规则

两条没有开关的默认行为

Java 门槛在启动前拦截，版本隔离始终开启 —— 都不需要用户配置。

启动前的 Java 检查

达标才进主界面；点「启动游戏」时按当前版本再算一次。

游戏版本需要的 Java
26.x（主线）25+
1.20 ~ 1.2121
1.17 ~ 1.1917
1.16 及更早8

阈值优先读已下载 <版本>.json 的 javaVersion.majorVersion，没下载时按版本号推断。一个 Java 都没有时，下载页会自动把「Java 运行时」勾上。

版本隔离

启动时 --gameDir 指向版本目录，存档与 Mod 不会串。

  • versions/26.3/原版
  • versions/26.3+fabric/加载器版
  • mods/随版本创建
  • saves/ · resourcepacks/随版本创建
  • shaderpacks/ · logs/随版本创建

Mod 与资源都装进对应版本的目录，不是全局 minecraft/mods/。始终开启，没有关闭开关。

安装

按发行版选择

Arch用sh安装;Fedora / openSUSE 走 COPR；Debian 系出 .deb；没有包管理器的环境用独立 ELF。

安装 / 指定 tag / 卸载
curl -fsSL https://raw.githubusercontent.com/zzxwithbus19/one-263-linux/main/install.sh | sh 
# 卸载
sudo pacman -Rns mc263
sudo dnf copr enable cxc123/one-263-linux
sudo dnf install mc263

说明

  • COPR 有签名
Tumbleweed（同一个 COPR 项目）
BASE=https://download.copr.fedorainfracloud.org/results/cxc123/one-263-linux
sudo rpm --import "$BASE/pubkey.gpg"
sudo zypper addrepo "$BASE/opensuse-tumbleweed-x86_64/" one-263-linux
sudo zypper refresh
sudo zypper install mc263

说明

  • COPR有签名
.deb(Ubuntu 26.04+ / Debian 13.7+)
bash install.sh 
make deb

说明

  • 脚本识别到 Debian 系会走 apt install ./*.deb

#发行版包管理器安装时会自动补全依赖

releases issues

常见问题

使用前需要知道的

能登录正版账号吗？

不能。启动参数是离线模式，只能玩单人和局域网

支持哪些发行版？

Arch 系(含 CachyOS);Fedora / openSUSE 走 COPR ;Debian 系用 .deb分发方式；其它发行版使用ELF文件

两个版本的存档 / Mod 会串吗？

不会。版本隔离始终开启
