mc263 是 Minecraft 26.3 的 Linux 原生启动器。不用 Electron、不用 CMake、不需要 moc，界面是手写的 Qt6 Widgets；启动前查 Java，启动时按版本隔离游戏目录。

功能

七个页面，各管一件事

下载、Mod、加载器、环境检查分开摆，不挤在同一个视图里。

启动游戏

版本下拉、玩家名、一键启动；QProcess 异步执行 java，日志实时刷新。启动日志同时落盘到 note/launch-*.log，只留最近 10 个。

QProcess / 日志落盘

下载游戏

在线版本列表（可勾预览版）、组件勾选、official 与 bmclapi 镜像、默认 10 并发；SHA1 校验 + 断点续传，已一致的文件跳过。

10 并发 / SHA1

Mod 下载

检索 Modrinth：关键词 + 加载器 + 游戏版本过滤，五种排序；双击安装、自动补齐 required 前置。同页还能装 Fabric / Quilt 加载器。

Modrinth / 无需 key

Mod 管理

已装 Mod 列表：启用 / 禁用（改 .disabled）、删除、按 SHA1 反查 Modrinth 检查更新，只认有新版本的文件。

启停 / 删除 / 更新

版本管理

左栏是已装版本，右栏是该版本的 Java 与兼容性查验：扫配置 / Mojang JRE / JAVA_HOME / PATH / /usr/lib/jvm，11 项逐条判定。

启动前闸门 · 11 项

资源

世界 / 资源包 / 光影分标签页，扫的是当前版本目录；导入 zip、启用 / 禁用、删除。世界不能禁用，只能删或换目录。

saves / packs / shaders

设置 / 内存

配色可选自动 / 系统调色板 / Noctalia（Material You）；内存默认交给 JVM，四段式内存条 2 秒刷新；语言跟随系统 locale。

无 -Xmx / 跟随 locale

运行规则

两条没有开关的默认行为

Java 门槛在启动前拦截，版本隔离始终开启 —— 都不需要用户配置。

启动前的 Java 检查

达标才进主界面；点「启动游戏」时按当前版本再算一次。

游戏版本需要的 Java
26.x（主线）25+
1.20 ~ 1.2121
1.17 ~ 1.1917
1.16 及更早8

阈值优先读已下载 <版本>.json 的 javaVersion.majorVersion，没下载时按版本号推断。一个 Java 都没有时，下载页会自动把「Java 运行时」勾上。

版本隔离

启动时 --gameDir 指向版本目录，存档与 Mod 不会串。

  • versions/26.3/原版
  • versions/26.3+fabric/加载器版
  • mods/随版本创建
  • saves/ · resourcepacks/随版本创建
  • shaderpacks/ · logs/随版本创建

Mod 与资源都装进对应版本的目录，不是全局 minecraft/mods/。始终开启，没有关闭开关。

安装

按发行版选择

主线是 Arch 的自建 pacman 源；Fedora / openSUSE 走 COPR 的 rpm；Debian 系出 .deb；没有包管理器的环境用独立 ELF。

安装 / 指定 tag / 卸载
curl -fsSL https://raw.githubusercontent.com/zzxwithbus19/one-263-linux/main/install.sh | sh -s -- --pacman

# 指定 tag（pre-release 也支持）
sh install.sh --tag up3-2

# 卸载
sh install.sh --uninstall

运行时依赖

  • qt6-base qt6-wayland
  • python curl

说明

  • 下载 .pkg.tar.zst 后 pacman -U 安装
  • 自建静态仓库由 repo-add 生成，不上 AUR
  • 依赖不代装，脚本只装 mc263 本体
COPR 源（推荐，Fedora 密钥签名）
sudo dnf copr enable cxc123/one-263-linux
sudo dnf install mc263

# 或者用一键脚本（会打印同样的两条命令）
curl -fsSL https://raw.githubusercontent.com/zzxwithbus19/one-263-linux/main/install.sh | sh

# 依赖
sudo dnf install qt6-qtbase qt6-qtwayland python3

说明

  • Fedora 45 起 RPM 默认 _pkgverify_level all，未签名包直接拒装
  • COPR 用 Fedora 密钥签名，dnf install 不需要 --nogpgcheck
  • 本地出包：bash packaging/build-rpm.sh
Tumbleweed（同一个 COPR 项目）
sudo rpm --import https://download.copr.fedorainfracloud.org/results/cxc123/one-263-linux/pubkey.gpg
sudo zypper addrepo https://download.copr.fedorainfracloud.org/results/cxc123/one-263-linux/opensuse-tumbleweed-x86_64/ one-263-linux
sudo zypper refresh one-263-linux
sudo zypper install mc263

# 依赖
sudo zypper install qt6-qtbase libQt6WaylandClient6 python3

说明

  • COPR 的 openSUSE chroot rpm 签了名，仓库元数据没签
  • 所以先 rpm --import 再 zypper addrepo，包签名照样验
  • 之后升级走 zypper update mc263
.deb（Ubuntu 26.04+ / Debian 13+）
sudo apt install ./mc263_26.3-4_amd64.deb

# 自己出包（需要 Qt6 开发包）
sudo apt install qt6-base-dev python3
make deb
# → dist/deb/mc263_26.3-4_amd64.deb

说明

  • 装包不需要编译器，Qt6 运行时由 apt 拉
  • 一键脚本识别到 Debian 系会自动走 apt install ./*.deb
  • 强制走 deb：sh install.sh --deb
免安装
chmod +x mc263-qt-26.3-x86_64
./mc263-qt-26.3-x86_64

# 自备 Qt6 运行时
sudo dnf install qt6-qtbase qt6-qtwayland python3      # Fedora
sudo pacman -S --needed qt6-base qt6-wayland python curl # Arch

说明

  • 不创建菜单项和图标，拷走 chmod +x 就能跑
  • 装在只读位置时，minecraft/ 与 .mc263/ 自动改放 ~/.local/share/mc263/
  • 强制走 ELF：sh install.sh --elf
安装脚本按 /etc/os-release 的 ID / ID_LIKE 判断发行版（不看 uname），签名失败就失败，不会自动 --nogpgcheck。想审一遍就先下载再执行。
Arch 包mc263-26.3-<rel>-x86_64.pkg.tar.zst Fedora / openSUSE rpmmc263-26.3-<rel>.fc45.x86_64.rpm Debian / Ubuntumc263_26.3-<rel>_amd64.deb 独立 ELFmc263-qt-26.3-x86_64

文件名里的 <rel> 以 Releases 页面为准；各产物同时附 SHA256SUMS。

常见问题

使用前需要知道的

没有 Java，能先把游戏下载下来吗？

能。检测不到 Java 时，下载页会自动出现「Java 运行时」组件并默认勾选；下载完成或手动指定 java 会重新扫描，达标就放行。

能登录正版账号吗？

暂时不能。启动参数是离线模式（--accessToken 0 --userType legacy），只能玩单人和局域网。正版登录要走 Microsoft OAuth → Xbox Live → XSTS → Minecraft Services 整条链路，还没做。

支持哪些发行版？

Arch 系（含 Manjaro / CachyOS）走自建 pacman 源；Fedora / openSUSE 走 COPR 的 rpm；Debian 系用 .deb；其它发行版自备 Qt6 运行时装独立 ELF。

Fedora 提示包没有签名、拒绝安装？

45 起 RPM 默认拒绝未签名包。最省事的是用 COPR 源；脚本遇到拒绝会直接停下来，把三条路打出来，不会替你放宽校验。

两个版本的存档 / Mod 会串吗？

不会。版本隔离始终开启，--gameDir 指向 versions/<版本>/，mods、saves、资源包、光影、日志都在各自目录下。

仓库会附带游戏文件吗？

不会。仓库里没有 Minecraft 游戏文件、Java 运行时或任何 Mojang / Microsoft 素材；下载器只从官方 CDN 或公共镜像取公开资源文件。

许可与声明

边界写清楚

源码许可

GPL-3.0-or-later。当前代码是全新的 C++23 实现，不含上游代码；上游未声明许可证，其构建脚本已从本仓库移除。

Qt6 链接方式

按 LGPL-3.0-only 动态链接。分发二进制时需随附 LGPL-3.0 文本、声明使用 Qt、保持动态链接以便替换，并提供 Qt 源码获取途径。

不包含的内容

Minecraft 游戏文件、Java 运行时、Mojang / Microsoft 版权素材都不在仓库内；下载到本地的第三方库与资源适用各自许可。

已知限制：暂不支持正版账号登录；游戏语言默认跟随系统 locale，识别不到回退 en_us；Wayland 为首选后端，缺插件时回退 XWayland，「关于」页能看到当前后端与 Qt 版本。
