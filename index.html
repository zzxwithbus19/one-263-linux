运行规则

两条没有开关的默认行为

Java 门槛在启动前拦截，版本隔离始终开启。两者都不需要用户配置。

启动前的 Java 检查

达标才进主界面，点「启动游戏」时会按当前版本再算一次。

游戏版本需要的 Java
26.x（主线）25+
1.20 ~ 1.2121
1.17 ~ 1.1917
1.16 及更早8

阈值优先读取已下载 <版本>.json 的 javaVersion.majorVersion；未下载时按版本号推断，core::requiredJavaMajor 有单测覆盖。检测不到 Java 时，下载页会自动提供「Java 运行时」组件。

版本隔离

启动时 --gameDir 指向版本目录，存档与 Mod 不会串。

  • versions/26.3/原版
  • versions/26.3+fabric/加载器版
  • mods/随版本创建
  • saves/ · resourcepacks/随版本创建
  • shaderpacks/ · logs/随版本创建

Mod 下载装进对应版本的目录，而不是全局 minecraft/mods/。始终开启，没有关闭开关。

安装

按发行版选择

主线是 Arch 的自建 pacman 源，Fedora / openSUSE 走 rpm；没有包管理器的环境可以用独立 ELF。

安装 / 指定 tag / 卸载
curl -fsSL https://raw.githubusercontent.com/zzxwithbus19/one-263-linux/main/install.sh | sh -s -- --pacman

# 指定 tag（含 pre-release）
sh install.sh --tag up3-1

# 卸载
sh install.sh --uninstall

运行时依赖

  • qt6-base qt6-wayland
  • python curl

说明

  • 下载 .pkg.tar.zst 后用 sudo pacman -U 安装
  • 自建静态仓库由 repo-add 生成，不上 AUR
  • 依赖需自行安装，脚本不代装
rpm 线
curl -fsSL https://raw.githubusercontent.com/zzxwithbus19/one-263-linux/main/install.sh | sh -s -- --rpm

# COPR 排队较慢时，可本地出包
bash packaging/build-rpm.sh

# 依赖
sudo dnf install qt6-qtbase qt6-qtwayland python3

说明

  • 完整 rpm 线在 fedora 分支维护，发版走 COPR
  • Fedora 45 / RPM 6.1 对包签名有要求
  • 本地构建产出 dist/*.rpm 与独立 ELF
免安装二进制
chmod +x mc263-qt-26.3-x86_64
./mc263-qt-26.3-x86_64

# 自备 Qt6 运行时
sudo pacman -S --needed qt6-base qt6-wayland python curl

说明

  • 不创建菜单项和图标
  • 其它发行版自备 Qt6 也能运行
  • 官方不为其提供打包支持
安装脚本按 dnf → zypper → pacman 顺序探测并自动选择，也可用 --pacman / --rpm / --elf 强制指定。若需审阅脚本内容，建议先下载查看再执行。

常见问题

使用前需要知道的

没有 Java，能先把游戏下载下来吗？

能。检测不到 Java 时，下载页会自动出现「Java 运行时」组件并默认勾选；下载完成或手动指定 java 后会重新扫描，达标即放行。

能登录正版账号吗？

暂时不能。启动参数为离线模式（--accessToken 0 --userType legacy），只能进行单人与局域网游戏。正版登录需要 Microsoft OAuth → Xbox Live → XSTS → Minecraft Services 整条链路，尚未实现。

支持哪些发行版？

打包主线是 Arch Linux（自建 pacman 静态仓库，不上 AUR）与 Fedora / openSUSE 的 rpm 线（COPR）。其它发行版若自备 Qt6 运行时，可直接使用独立 ELF，但官方不提供打包支持。

仓库会附带游戏文件吗？

不会。本仓库不包含 Minecraft 游戏文件、Java 运行时或任何 Mojang / Microsoft 版权素材。下载器只从 Mojang 官方 CDN 或公共镜像获取公开资源文件，下载到本地的内容各自适用其原有许可。
